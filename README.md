# WalletFlow

WalletFlow is a full-stack personal finance tracker for recording income and expenses, monitoring the current balance, and reviewing transaction history.

## Features

- Account registration and login
- Password hashing with bcrypt
- JWT-protected API routes
- Income and expense tracking
- Transaction history and deletion
- Balance calculation
- Currency conversion
- Responsive dashboard

## Tech Stack

- HTML, CSS, and JavaScript
- Node.js and Express
- SQLite
- JSON Web Tokens and bcrypt



*The application currently uses SQLite. On Render's free web-service plan, the local database is temporary and can reset after the service restarts, redeploys, or wakes from inactivity. This is suitable for a portfolio demo but not for storing production data.
